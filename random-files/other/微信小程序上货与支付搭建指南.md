## 先搞清楚：你必须具备的条件

微信支付的官方接入指引写得很明确：小程序必须完成微信认证，且主体得是**个体工商户、企业、事业单位、政府机关或社会组织**，个人主体暂不支持申请微信支付。

你需要提前备齐：

- **营业执照**（个体工商户最低成本，网办几百块）
- **法人身份证**正反面
- **结算账户**：企业需对公账户；个体工商户可绑定法人个人银行卡
- 特殊类目额外资质（如食品需《食品经营许可证》）

> 💡 费率参考：微信支付申请本身免费，交易按类目收服务费，**一般为 0.6%–1%**，结算周期多为 T+1。

这是目前个人/小商家卖货**最快**的路径——官方提供，**免 300 元/年认证费**，自动生成小程序前端，不用写代码。

2. **开通微信支付**
   小商店会**自动帮你申请微信支付商户号**，你只需在后台完善结算账户信息（法人银行卡或对公账户），1-3 天审核通过后买家即可付款。**仅收取 0.6% 交易手续费**，无其他费用。

3. **上架商品**
   登录小商店后台（电脑端或"微信小商店助手"小程序），进入"商品管理" → "新增商品"：
   - 填写商品名称、价格、库存

整个流程**3 天内**可以跑通，适合商品数量不多、要快速开卖的场景。

## 🛠 路线 B：第三方 SaaS 搭建自定义小程序

如果你希望小程序页面更个性化、或者需要会员系统、营销工具、分销等进阶功能，选这条路。

**核心流程：**

1. **注册并认证小程序**
   微信公众平台注册小程序账号，主体选企业/个体工商户，**缴纳 300 元/年认证费**（已有认证公众号可复用资质免交）。认证通过拿到 AppID 和 AppSecret。

2. **申请微信支付商户号**
   到微信支付商户平台提交营业执照、银行账户等资料，审核 1-2 工作日，通过后拿到商户号（mchid）和 API 密钥。**需将商户号与小程序 AppID 双向绑定**。

3. **用 SaaS 平台装修 + 上货**
   诸如码云数智等零代码平台，选商城模板 → 拖拽装修 → 商品管理里单个添加或 Excel 批量导入（填名称、价格、库存、多规格、主图详情图）。

4. **对接支付**
   在 SaaS 后台"支付设置"填入商户号和 API 密钥，**建议下 1 分钱测试单验证通路**。

5. **完成 ICP 备案**
   小程序上线前必须备案，在微信公众平台提交资料，通信管理局审核 3-7 个工作日。

6. **提交审核上线**
   预览测试 → 提交微信审核 → 1-3 工作日出结果 → 发布。

## ⚙️ 如果你要坚持自研（不推荐"简易"场景）

自行开发接入微信支付的关键技术节点：

| 环节 | 要点 |
|---|---|
| **下单** | 服务端调用微信 JSAPI 统一下单接口，传入订单金额、商品描述、用户 OpenID |
| **调起支付** | 小程序端拿到 prepay_id 等参数后，调用 `wx.requestPayment` 拉起收银台 |
| **异步回调** | 微信向你的 `notify_url` 推送支付结果，**订单状态以这个异步通知为准**，不能只依赖前端返回值 |
| **硬要求** | 必须有**已备案 + HTTPS** 的域名；交易类小程序还必须满足《交易类小程序运营规范》，接入订单发货管理功能 |

> ⚠️ 个人小程序即使写了代码也调不起微信支付，**这是平台限制而非技术问题**。
