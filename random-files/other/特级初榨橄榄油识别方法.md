# yuanbao response

EVOO 是 Extra Virgin Olive Oil 的缩写，中文叫“特级初榨橄榄油”，是橄榄油里等级最高的一种。它本质上是“橄榄果榨出来的果汁”，不是后期精炼出来的油。

## 一、EVOO 到底是什么标准

按国际橄榄油理事会（IOC）和主流国标口径，特级初榨要同时满足几件事：[citation:7][citation:13]

- **只物理压榨**：洗果、破碎、搅拌、离心、过滤等机械/物理方式取油，不用溶剂、不化学精炼。[citation:1][citation:15]
- **低温处理**：很多厂家标“冷榨/cold pressed/cold extracted”，行业常用参考是提取温度不超过约 27℃（有的资料写 30℃），避免高温把香气和多酚打掉。[citation:1][citation:13]
- **酸度低**：游离酸度以油酸计 ≤0.8g/100g。注意“酸度”是化验指标，不代表你尝着酸；果坏了、运输久、氧化了，酸度容易上去。[citation:7][citation:1]
- **过氧化值/氧化指标合格**：比如常见参考过氧化值 ＜20 meq O₂/kg，具体看执行标准。[citation:1]
- **感官无缺陷+有果香**：专业评审小组盲品，缺陷分中位数为 0，果香分＞0。家里人不用按这个来，但“有清新果香、青草香，入口微苦、咽下去辣喉”是典型好信号。[citation:5][citation:2]

对比一下其他常见等级：
- 初榨 Virgin：物理压榨，但酸度可到 0.8%–2%，或感官有小缺陷；
- 精炼橄榄油：用有缺陷的初榨油经脱酸脱色除臭等处理，风味淡、多酚少；
- 纯/light 橄榄油：多是精炼+少量初榨调和，风味中性；
- 橄榄果渣油 Pomace：从榨完的渣里用溶剂再提，按国标不能叫“橄榄油”。[citation:11][citation:4]

## 二、买的时候怎么看标签

按国内 GB/T 23347 和选购常识，优先核对这几项：[citation:11][citation:5]

1. **等级名要对**：中文“特级初榨橄榄油”；进口油看 Extra Virgin（英）、Extra Vergine（意）、Extra Virgen（西）。只写“橄榄油”“纯橄榄油”“精选橄榄油”“特级橄榄油”都不算数。
2. **配料表只有它自己**：特级初榨的配料应只有“特级初榨橄榄油”。出现“精炼橄榄油”“橄榄果渣油”“葵花籽油/大豆油”等，就是混合/调和/果渣类，不是纯 EVOO。[citation:11]
3. **看酸度/酸价**：包装标酸度≤0.8%更稳；国标对特级初榨酸价有更严的限量口径，但市售常标≤0.8%作为等级线。酸度不是越低绝对越好，精炼油也能把酸度做很低，所以必须配合“初榨、无精炼”一起看。[citation:5][citation:11]
4. **看日期而不是只看保质期**：优先看油橄榄果“采收期/采摘日期”，再看包装/分装日期。EVOO 越新越好，买回来活性也随时间掉；一般选采收后 12–18 个月内更安心，超过两年就算没坏，香气和多酚也差了。[citation:5][citation:8]
5. **看工艺和包装**：标“物理冷榨/冷提取”比只写“精炼”靠谱；瓶子优先深色玻璃或避光容器，透明瓶长期见光容易氧化。[citation:11][citation:1]
6. **产地和认证作加分项**：单一批次、单一庄园、品种（如 Arbequina、Picual、Koroneiki）信息越细越利于追溯；欧盟 PDO/DOP、PGI/IGP、有机认证可参考，但不是“没认证就不是真 EVOO”。[citation:4][citation:11]
7. **价格预警**：真特级初榨人工、鲜果、冷榨、避光储运都不便宜。低价大瓶、促销几块钱几百毫升、还标 Extra Virgin 的，要高度怀疑是精炼调和或旧油重新贴牌；但高价也不等于一定好，最终看标签和风味。[citation:6][citation:8]

## 三、买回家怎么用感官粗筛

倒一点到小杯或小碟，温到室温别冰着闻：

- **闻**：好 EVOO 有青橄榄、青草、番茄叶、苹果、杏仁、罗勒一类清新植物香。年轻单果品种常更青、更辣；熟采油更果甜、更柔和。
- **尝**：入口可有橄榄果甜，接着微苦，咽下喉部有辛辣感——这是多酚、刺激物的正常表现，不是变质。[citation:5][citation:2]
- **异常味直接弃用**：哈喇味、油漆味、霉味、土腥、酒酸、醋味、金属味、烂果味，或者完全没味像色拉油，都说明要么不是特级初榨、要么已经氧化/储藏坏掉。[citation:2][citation:5]

颜色别当硬标准：EVOO 可以是黄绿、金黄、浅黄，取决于品种和成熟度；未过滤的会略浊，过滤的清亮，都不能单靠“绿不绿”判断真假。[citation:3][citation:17]

冷藏结晶也只能作玩具测试：低温下橄榄油会变稠、出部分结晶，但掺什么油、什么比例，家庭靠结冰状态判断不准；尤其不同单不饱和脂肪酸组成、过滤与否差别很大，别迷信“不结冰就是假油”。[citation:17][citation:3]

## 四、几个常见误区

- “EVOO 不能炒菜”：它能炒，烟点大概 190–210℃，家常炒、煎多数没问题；但高温长时间爆炒、反复煎炸会浪费香气和多酚，凉拌、蘸面包、出锅淋油更值。[citation:4][citation:7]
- “越绿越高级”：不对，绿通常来自未熟果/某些品种，成熟果出金黄油也很顶级。
- “酸度 0.1 一定最好”：初榨油低酸度是好事，但精炼油也能低酸度；必须确认是初榨、无精炼、感官达标。
- “有沉淀就是坏”：未过滤新油少量细小沉淀可正常；但要是发霉、起泡、异味、瓶口粘腻，就是变质。

# yuanbao response

按你给的配料“精炼橄榄油 + 特级初榨橄榄油”、酸度≤0.5%、品牌“安达鲁西/安达露西”来判断：

## 一、它整体算什么等级
按国标 GB/T 23347-2021，橄榄油按加工工艺只分三大类可食用：[citation:1]
- 初榨橄榄油：特级初榨、优质初榨、初榨橄榄灯油（灯油不可直接吃）
- 精炼橄榄油：用初榨灯油/次级初榨经精炼得到
- 混合橄榄油：精炼橄榄油 + 可直接食用的初榨橄榄油调出来的

配料同时出现“精炼橄榄油”和“特级初榨橄榄油”，标准归类就是**混合橄榄油**，不是特级初榨，也不是纯精炼。[citation:2][citation:5]  
市场上常叫“纯正橄榄油”“中式烹饪橄榄油”“凉拌炒菜两用”的大瓶装，很多就是这种混合油。

## 二、酸度≤0.5% 怎么说
注意两个口径：
- 商家宣传的“酸度≤0.5%”通常指游离脂肪酸（以油酸计）≤0.5g/100g，也就是0.5%。混合油把精炼油（酸很低）和特级初榨（≤0.8%）调到≤0.5%是完全可能的。
- 国标 GB/T 23347 的“酸价”用 KOH mg/g：特级初榨≤1.6、精炼≤0.6、混合≤2.0；旧/国际常用游离酸度：特级初榨≤0.8%、精炼约≤0.3%、混合≤1.0%。[citation:1][citation:12]

所以“酸度0.5%”本身不证明它是特级初榨——精炼油也能很低酸，关键看配料和品名。

## 三、合不合规，看瓶身这几点
1）产品名称  
- 只写“特级初榨/Extra Virgin/特级橄榄油”，但配料含精炼橄榄油 → **不合规、误导**。特级初榨配料只能有“特级初榨橄榄油”一项。[citation:2]  
- 名称写“混合橄榄油”，配料写精炼+特级初榨，酸度标≤0.5% → 合规（按混合油标准判定）。  
- 名称写“精炼橄榄油”但还加特级初榨 → 不对，应改混合。  
- 只写“橄榄油”三个字不写具体工艺 → 按新国标标签不规范。[citation:1][citation:2]

2）标准号  
看执行 GB/T 23347（2021 或 2009 均可，2021 更现行）；如果是调和油加了葵花/大豆等，应走“食用调和油”标准，不应叫橄榄油。[citation:2]

3）有没有果渣油  
配料若出现“油橄榄果渣油/olive pomace oil”却叫橄榄油 → 不合规。果渣油不能叫橄榄油。[citation:2][citation:9]

4）品牌对照  
“安达露西”（中粮，Andalucía/安达卢西亚）线上有两条线：
- 特级初榨款：配料只“特级初榨橄榄油”、酸度≤0.5%、小瓶/1L/235ml 之类；[citation:6][citation:11]
- 大瓶“纯正/1.76L/5L”混合款：精炼+特级初榨、酸度≤0.5%，用于中式炒。公开促销里 5L 款就明确写“精炼+特级初榨混合橄榄油”。[citation:13][citation:3]

如果你买的那瓶正面大字是“特级初榨”、配料却含精炼，不管酸度多低都建议按标签瑕疵/不实投诉或退换；如果正面本来就是“纯正/混合/橄榄油（精炼+特级初榨）”，那就属混合油，没毛病，但别当特级初榨买来凉拌生食。

## 四、实用结论
- 想凉拌、蘸面包、追求多酚果香：要买配料只有“特级初榨橄榄油”、品名特级初榨、酸度≤0.8%（很多标≤0.5更优）、有采摘年份的。
- 你这瓶“精炼+特级初榨、酸度0.5%”：定位是混合橄榄油，适合煎炒炖煮；风味和营养活性不如纯特级初榨，价格也应明显低于纯EVOO。
- 避坑：看到“特级初榨”+“精炼”同配料，直接按标签不合格看待；看到酸度0.5%但没写初榨工艺，也别自动当EVOO。

如果你把瓶身完整文字（产品名称、配料顺序、净含量、标准号、酸度/酸价、采摘期、是否“纯正/混合/冷榨”）发我，可以直接判断它该归哪类、是不是虚标。

# yuanbao response

按“中式烹饪橄榄油”+配料“精炼橄榄油、特级初榨橄榄油”+酸度≤0.5%来看，它的本质不是特级初榨，而是**混合橄榄油**（blended/mixed olive oil）。合不合规，看瓶身有没有把“真实工艺等级”标出来。

## 一、按国标归哪一档
GB/T 23347-2021 把可食用橄榄油按工艺分：
- 初榨：特级初榨、优质初榨、初榨橄榄灯油（灯油不能直接吃）
- 精炼橄榄油
- 混合橄榄油：精炼橄榄油＋可直接食用的初榨（特级或优质）调出来 [citation:6][citation:7]

你这瓶配料同时有“精炼+特级初榨”，标准归类就是**混合橄榄油**，不管前面叫“中式烹饪”“纯正”“经典”“炒菜专用”都改不了这个工艺身份。[citation:3][citation:9]  
如果正面大字只写“特级初榨/Extra Virgin/特级橄榄油”，但配料含精炼，属于标签不实；如果正面只写“中式烹饪橄榄油”五个字、全瓶找不到“混合橄榄油”或至少“精炼/初榨”工艺类别，按新国标也不规范——国标要求按工艺标真名，不能只写“橄榄油”或自造场景名代替等级。[citation:3][citation:7]

## 二、酸度≤0.5%怎么看
商家写的“酸度≤0.5%”通常指游离脂肪酸（以油酸计）≤0.5g/100g。混合油完全能做到：精炼油本身酸很低，配一点特级初榨，整体很容易压到0.5%以下。所以“酸度0.5%”不证明它是特级初榨，只说明调出来很“顺”。

国标另一套口径是酸价（KOH）：
- 特级初榨 ≤1.6 mg/g
- 优质初榨 ≤3.0 mg/g
- 精炼 ≤0.6 mg/g
- 混合 ≤2.0 mg/g [citation:2][citation:7]

也就是说混合油酸价只要≤2.0就达国标；它标“酸度0.5%”比混合油下限严得多，属于营销卖点，不是特级证明。

## 三、“中式烹饪”这个叫法本身违规吗
不必然违规，但要看怎么排：
- 合规示例：产品名“混合橄榄油”，副标/广告语“中式烹饪用油/适合煎炒炖”，配料精炼橄榄油、特级初榨橄榄油，执行GB/T 23347，酸度/酸价标真实值 → 没问题。
- 边缘但不建议买：正面只写“中式烹饪橄榄油”，侧面小字才写“混合”，没有独立“产品名称=混合橄榄油” → 按新国标口径偏不规范，可投诉可退。
- 违规：正面“特级初榨/中式烹饪特级”之类，配料却含精炼 → 虚假等级。
- 另外混合油不需要标“油橄榄鲜果采收期”；只有特级/优质初榨强制标采收期。它没标采收期是正常的，不等于冒充。[citation:6]

## 四、安达露西/安达鲁西的情况
中粮安达露西（Andalucía系）通常两条线：
- 特级初榨线：配料只“特级初榨橄榄油”，酸度≤0.5%，小瓶/1L深色瓶，标采收期，凉拌蘸面包用；
- 纯正/中式烹饪/大桶线：配料“精炼橄榄油+特级初榨橄榄油”，酸度≤0.5%，执行GB/T 23347，定位煎炒炖。[citation:8]  
如果你买的是后者，按“混合橄榄油”理解就对：烟点比纯EVOO稳、风味比纯EVOO淡、多酚和果香少一截，价格应明显低于纯特级初榨。

## 五、你这瓶怎么用、值不值
- 煎炒、爆炒、炖肉、炸东西：混合油反而比纯特级初榨合适，精炼部分耐热、油烟相对少；
- 凉拌、沙拉、蘸面包、出锅淋菜：不如纯特级初榨，果香苦辣感会弱很多；
- 价格判断：同样1L，如果它卖得跟纯EVOO差不多贵，就不划算；大桶5L/1.76L按“混合油”定价才合理。

买之前复看瓶身三行就行：产品名称是否含“混合橄榄油”→配料是否精炼在前/特级在后（按用量排序）→执行标准GB/T 23347、酸度或酸价与等级匹配。若这三行对不上，再便宜也按标签问题处理。

如果你把瓶身“产品名称、配料顺序、净含量、标准号、酸度/酸价、生产/分装日期、是否标采收期”原文发我，可以直接判它算正规混合油还是擦边虚假标注。
