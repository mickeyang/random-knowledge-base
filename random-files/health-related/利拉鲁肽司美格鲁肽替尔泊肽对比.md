# yuanbao response

这三款都属于“肠促胰素类”注射药，用于2型糖尿病控糖和/或肥胖/超重长期体重管理，但靶点和用法不完全一样。

## 一、分别是什么

**利拉鲁肽 Liraglutide**
- 类别：GLP-1受体激动剂（单靶点）[citation:4]
- 给药：皮下注射，每日1次，不限餐；降糖常用维持1.2–1.8 mg/日，减重剂型（Saxenda类）可到3.0 mg/日[citation:6][citation:13]
- 国内：2型糖尿病获批较早；减重用于成人肥胖/超重合并症（国内2023年纳入减重获批名单）[citation:2][citation:6]
- 特点：老药、证据多、每日打，减重幅度相对小

**司美格鲁肽 Semaglutide**
- 类别：GLP-1受体激动剂（单靶点，周制剂）[citation:4]
- 给药：皮下注射每周1次（Ozempic降糖、Wegovy减重）；另有口服片Rybelsus主要用于2型糖尿病降糖，每日1次[citation:1][citation:4]
- 减重剂量：国内/欧美减重通常逐步加到2.4 mg/周；降糖起始更低（如0.25→0.5→1.0 mg/周）[citation:13][citation:1]
- 国内：减重2024年获批，用于BMI≥28，或≥24伴至少一种体重相关合并症[citation:2][citation:9]
- 特点：每周一次、降糖和减重都强于利拉鲁肽

**替尔泊肽 Tirzepatide**
- 类别：GIP+GLP-1双受体激动剂（双靶点）[citation:3][citation:13]
- 给药：皮下注射每周1次；起始2.5 mg，每4周可加2.5 mg，维持5/10/15 mg[citation:3][citation:13]
- 国内：2型糖尿病和减重均获批（减重2024年），也可用于部分成人肥胖伴中重度阻塞性睡眠呼吸暂停等；减重用于BMI≥28，或≥24伴合并症[citation:3][citation:2][citation:9]
- 特点：双靶点，平均降糖和减重幅度通常大于单GLP-1；胃肠反应仍最常见

## 二、共同机制与相互关系

三者的底层逻辑都模仿肠道餐后激素：
- 促进葡萄糖依赖的胰岛素分泌、抑制胰高糖素 → 降餐后/空腹血糖
- 延缓胃排空 → 早饱、吃得少
- 作用于中枢食欲通路 → 减少饥饿、控制总热量[citation:4][citation:11]

区别在“打几个靶点”：
- 利拉鲁肽、司美格鲁肽＝只打GLP-1受体
- 替尔泊肽＝同时打GIP+GLP-1，理论上对食欲、胰岛素敏感性、脂肪代谢调控更强[citation:3][citation:13]

大致效力（平均、个体差异大）：
- 利拉鲁肽减重约5%–8%体重，HbA1c降约1.0%–1.5%[citation:4][citation:11]
- 司美格鲁肽减重约12%–15%，HbA1c降约1.5%–1.8%[citation:4][citation:11]
- 替尔泊肽减重约15%–20%（高剂量试验可更高），HbA1c降约2.0%–2.4%[citation:4][citation:11]

> 关系总结：利拉鲁肽和司美是“同门单靶点”，司美比利拉鲁肽更长效、每周打、减重更强；替尔泊肽是“升级双靶点”，不属于GLP-1单药，但副作用谱系和禁忌与单GLP-1大量重叠。

## 三、常见副作用

多数出现在刚开始用、加量期，随后减轻：
- 恶心、呕吐、腹泻、便秘、腹痛、消化不良、腹胀
- 食欲下降、早期饱腹、轻微头晕、乏力
- 注射部位红/痒/硬结（皮下注射常见）[citation:2][citation:3][citation:6][citation:9]

较少见但要重视：
- 急性胰腺炎：持续上腹痛、向后背放射、伴呕吐 → 停药就医[citation:6][citation:3]
- 胆囊问题：胆泥、结石、胆囊炎（尤其快速减重后）[citation:2][citation:14]
- 脱水相关急性肾损伤：严重呕吐腹泻又喝水少时发生[citation:3][citation:14]
- 低血糖：单用本类很少；联磺脲类/胰岛素时风险明显升高[citation:6][citation:3]
- 心率增快、心悸[citation:3][citation:1]
- 过敏：皮疹、面唇舌肿、喘憋，罕见但需急诊[citation:1][citation:3]
- 甲状腺C细胞肿瘤警示：动物实验有风险，人未证实；有甲状腺髓样癌个人/家族史、MEN2者禁用[citation:4][citation:9][citation:6]
- 其他：替尔泊肽可伴脱发、胃食管反流；司美/替尔泊肽快速改善血糖时糖尿病视网膜病变需复查眼科；延误胃排空可影响口服药吸收（如口服避孕药需评估）[citation:3][citation:1][citation:2]

## 四、谁一般不用/先问医生

- 妊娠、备孕、哺乳；儿童青少年按具体药和年龄，不自行用
- 甲状腺髓样癌病史/家族史、MEN2
- 既往急性胰腺炎、慢性胰腺炎反复发作者慎用
- 严重胃轻瘫、严重胃肠梗阻、活动性炎症性肠病急性期
- 中重度肝肾功能异常需个体化；终末期肾衰用替尔泊肽经验有限[citation:3]
- 正在用胰岛素/磺脲，需医生调低后者以防低血糖[citation:6][citation:3]

## 五、用药替换与搭配

- 不自行把利拉鲁肽+司美+替尔泊一起打，也不随意叠加多种GLP-1/GIP类；同换同加都由医生按血糖、体重、胃肠耐受、心血管/肾病因素定。
- 从利拉鲁肽换司美：多为“每日单靶点→每周单靶点”，减少打针频率、增强效力。
- 从司美换替尔泊肽：从单靶点换双靶点，减重/降糖潜力更大，但胃肠反应和加量节奏要重来。
- 计划全麻/胃镜手术：这类药延缓胃排空，术前停药时间按药品和手术类型定（替尔泊肽/司美通常按周制剂提前数天，利拉鲁肽每日提前1天或不等），务必提前告诉麻醉医生。[citation:3]

# yuanbao response

单纯为“瘦几斤/更好看”而用利拉鲁肽、司美格鲁肽、替尔泊肽，风险不低，而且在国内都属于严格管理的处方药，原则上先由医生评估再开，不建议自己网购/代购打。[citation:10][citation:16]

## 一、什么算“有用药指征”，什么算滥用

国内减重版获批思路（不同药略有差异，亚洲标准常比欧美更严）：
- 司美/利拉鲁肽类：常见按 BMI≥30 单纯肥胖，或 BMI≥27 且合并高血压、高血糖、血脂异常、睡眠呼吸暂停、脂肪肝等至少一种代谢问题 [citation:10][citation:3]
- 部分国内材料和说明书按亚洲人群写：BMI≥28 单纯肥胖，或 BMI≥24 且合并上述代谢病/体重相关并发症 [citation:18][citation:19][citation:7]
- 替尔泊肽减重：国内常用口径 BMI≥28，或 BMI≥24 合并至少一种代谢异常 [citation:7][citation:6]

也就是说：
- 只是“微胖、小基数、想再瘦5–10斤、拍照更上镜”→通常不符合正规减重用药指征
- BMI 正常甚至偏瘦还打→风险明显升高，可能出现剧烈呕吐、脱水、电解质紊乱，甚至因过度抑制进食导致营养不良、月经紊乱、厌食倾向 [citation:2][citation:15][citation:13]
- 有过胰腺炎、胆囊问题、严重胃病、甲状腺髓样癌风险、妊娠备孕哺乳等→很多情况根本不该自行试

## 二、单纯减重的主要风险

常见（多在起始/加量期）：
- 恶心、呕吐、反酸、腹胀、腹泻或便秘、食欲很差、乏力 [citation:4][citation:11]
- 部分人因吃太少出现脱发、月经紊乱、低蛋白、贫血 [citation:4][citation:15]

少见但严重：
- 急性胰腺炎：持续上腹痛、向后背放射、伴呕吐→急诊 [citation:14][citation:11]
- 胆囊问题：胆泥、结石、胆囊炎，快速减重本身也会推高风险 [citation:8][citation:4]
- 脱水→急性肾损伤，尤其吐泻又喝水少
- 甲状腺C细胞肿瘤警示：有甲状腺髓样癌个人/家族史、MEN2通常禁用 [citation:10][citation:14]
- 严重胃轻瘫、活动性炎症性肠病、肠梗阻倾向者不友好 [citation:8][citation:14]
- 心率增快、心悸；联用胰岛素/磺脲才可能明显低血糖（单纯减重、非糖尿病单用相对少）
- 自行加量、非正规渠道买药：假药、冷链失效、剂量标错，已有自行注射高剂量进急诊的案例 [citation:2][citation:13][citation:9]

另外停药不维持饮食运动，很多人会反弹。[citation:4][citation:15]

## 三、是不是“必须医生评估”

正规路径下是：
- 这三款都是处方药，正规药房/医院凭医生处方拿；线上“秒开处方、不问诊”不靠谱 [citation:12][citation:6]
- 医生评估通常看：身高体重算BMI、腰围、既往体重史；血糖/糖化、血脂、肝功能、肾功能、尿酸、甲状腺（功能±超声）、胆囊/胰腺病史、胃肠动力、妊娠可能、精神进食状态、现在用药 [citation:20][citation:5]
- 符合指征后也是小剂量起始、按耐受逐步加量，不是一上来用最高剂量 [citation:17][citation:2]
- 用上后复查体重、副作用、代谢指标，必要时调药或停 [citation:6][citation:20]

什么情况别自己试、直接先就医/不建议用：
- 备孕、已孕、哺乳；未成年人（减重用需专科严格评估）
- 甲状腺髓样癌本人/家属史、MEN2
- 既往急性胰腺炎、反复胰腺炎；严重胆石/胆囊炎活动期
- 严重胃轻瘫、幽门梗阻史、活动性克罗恩/溃疡性结肠炎重症
- 严重肝肾功能不全、终末期肾病
- BMI<24（部分人<18.5更不用说）只是想更瘦、容貌焦虑

如果属于“BMI 24–27但没任何代谢问题，只想塑形”，一般先走3–6个月饮食+运动+睡眠干预；效果不佳且医生判断有隐藏代谢异常，再讨论药物，而不是自己打。[citation:18][citation:19]

要不要按你的身高、体重、年龄、有没有高血压/脂肪肝/糖尿病/胆囊问题，直接判断你更靠近“可评估用药”还是“先生活干预”？
